# SSAC 2027 results

Each `taskN/` directory contains the CSVs produced by `scripts/taskN_*.py`. The basename mapping is direct: for example, the former flat `task2_fold_performance.csv` is now `task2/fold_performance.csv`; its bytes and SHA-256 are unchanged.

`headline_results.csv` collects the claims used by the abstract and README. `provenance/decisions_log.md` records analysis decisions, and `provenance/environment.json` consolidates the task environment stamps.
